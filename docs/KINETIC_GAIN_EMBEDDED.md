# Kinetic Gain Embedded — tie-back

## What this repo demonstrates

This repo demonstrates the **rights-window governance** primitive — release changes tied to approval blockers, publishing posture, and operator-safe sequencing.

## How Kinetic Gain Embedded extends it

Kinetic Gain Embedded is security-first embedded analytics for B2B SaaS.
It extends this primitive to rights-aware and revenue-aware in-product analytics for publishing, release, and commercial workflows, wrapped in:

- signed JWT authentication
- semantic-layer row-level security (RLS)
- read-only data connectors
- AST SQL validation
- append-only audit events
