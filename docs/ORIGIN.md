# Origin

Publishing operations are not just a schedule problem. They are a rights, approval, and release problem. The moment a holdback changes or a clearance drifts, teams need a surface that maps release pressure to downstream storefronts, promo packets, and the next safe move.

We built `rights-window-release-planner` to make that operating layer explicit. The point is not to replace a CMS or rights system. The point is to show what a Media / Publishing operator surface should look like when the audience needs to manage release pressure, downstream approvals, and publishing posture with real revenue consequences attached.
